CHIDOZIE TECHNOLOGIES WEBSITE — SETUP

This is a multi-page starter website styled to match the reference video:
light navigation bar, charcoal sections, gold accents, large hero, product cards,
services, about, quote form and privacy policy.

FILES
- index.html       Homepage
- products.html    Product catalogue
- services.html    Services
- about.html       About Us
- contact.html     Quote/enquiry form
- privacy.html     Privacy policy
- styles.css       Shared design
- script.js        Mobile menu, footer year and quote form

IMPORTANT: ADD YOUR EXISTING PRODUCT PHOTOS
Copy your existing product image files into the images folder in this website.
The code currently looks for these names:
- hotel-lock.jpeg
- encoder.jpeg
- key-card.jpeg
- advant-panels.jpeg
Optional fallback names:
- electronic-lock.jpeg
- entrance-panel.jpeg
- card-key.jpeg

The image filename must match the HTML exactly. For example, advant-panels.jpeg
is different from advent-panels.jpeg. If your existing image has a different name,
either rename it or update the matching src in the HTML.

HOW TO USE IN VS CODE
1. Make a backup of your current project first.
2. Extract this ZIP file.
3. Copy the HTML, CSS and JS files into your ChidoBoss-Store folder.
4. Copy your real product photos into the images folder. Do not delete your existing images.
5. Open index.html in your browser or use the Live Server extension in VS Code.
6. Check every page and every image.

BEFORE PUBLISHING
- Add the real business email to script.js in the businessEmail variable.
- Add the correct business phone, WhatsApp link, address and social links if desired.
- Check product descriptions, availability and prices with the business owner.
- The quote form currently opens the visitor's email application; it does not store
  messages on a server. A server-side form service is needed for direct submissions.
- This starter site does not automatically publish online or guarantee Google
  AdSense approval. Add accurate business details, a working contact method,
  suitable legal pages and original useful content before applying.
